# Forava YouTube Content Strategy

**Version:** 1.0
**Date:** January 2026
**Channel:** @forava (to be created)
**Focus:** Chinese New Year Campaign

## Executive Summary

This document outlines a comprehensive YouTube content strategy for Forava, initially focused on **Chinese New Year** as the launch cultural context. The strategy covers four content pillars: Tutorials, Cultural Education, Celebration Stories, and Shorts. It includes specific video concepts, production workflows, and integration with AI-powered video and voice generation tools.

### Content Goals
- **Tutorials:** Drive app downloads through how-to content
- **Cultural Education:** Build authority on Chinese New Year traditions
- **Celebration Stories:** Emotional connection, family-focused content
- **Shorts:** Viral reach and algorithm discovery

### Production Goal
Produce **2 long-form videos + 5 Shorts per week** using AI-assisted workflows to minimize production costs while maintaining quality.

## 6. AI Tool Integration for Video Production

### 6.1 Voice Generation Tools

#### Primary: ElevenLabs
**Use Case:** Professional voiceovers for tutorials and educational content

**Integration:**
```
API: https://api.elevenlabs.io/v1/text-to-speech
Model: eleven_multilingual_v2
Voice: Custom cloned voice or "Rachel" (warm female)
```

**Workflow:**
1. Write script in Google Docs
2. Export to plain text
3. Send to ElevenLabs API
4. Download MP3
5. Sync with video in editor

**Pricing:** $22/month (Creator) = 100K characters ≈ 10-15 videos

**Best For:**
- Tutorial voiceovers
- Educational narration
- Story narration

---

#### Secondary: OpenAI TTS
**Use Case:** Quick drafts, cost-effective bulk content

**Integration:**
```python
from openai import OpenAI
client = OpenAI()

response = client.audio.speech.create(
    model="tts-1-hd",
    voice="nova",  # warm, friendly voice
    input="Your script text here"
)
response.stream_to_file("output.mp3")
```

**Pricing:** $15/1M characters (tts-1) or $30/1M (tts-1-hd)

**Best For:**
- Draft versions
- Shorts voiceovers
- High-volume production

---

#### Tertiary: Google Cloud TTS
**Use Case:** Mandarin/Cantonese voiceovers for multilingual content

**Voices:** WaveNet Mandarin (cmn-CN), Cantonese (yue-HK)

**Best For:**

- Authentic cultural phrases

## Appendix B: AI Tool API Integration Examples

### ElevenLabs Voice Generation for CNY Content
```python
import requests

ELEVENLABS_API_KEY = "your_api_key"
VOICE_ID = "your_voice_id"

def generate_cny_voiceover(text, output_path):
    url = f"https://api.elevenlabs.io/v1/text-to-speech/{VOICE_ID}"

    headers = {
        "Accept": "audio/mpeg",
        "Content-Type": "application/json",
        "xi-api-key": ELEVENLABS_API_KEY
    }

    data = {
        "text": text,
        "model_id": "eleven_multilingual_v2",
        "voice_settings": {
            "stability": 0.5,
            "similarity_boost": 0.75
        }
    }

    response = requests.post(url, json=data, headers=headers)

    with open(output_path, 'wb') as f:
        f.write(response.content)

    return output_path

# Usage
script = """
Welcome to Forava. In this tutorial, I'll show you how to
create a beautiful Chinese New Year gift for your family
in under five minutes. 新年快乐!
"""

generate_cny_voiceover(script, "cny_tutorial_intro.mp3")
```

import requests

RUNWAY_API_KEY = "your_api_key"

def generate_cny_broll(prompt: str, duration: int = 4):
    """Generate CNY-themed B-roll footage from text prompt"""

    url = "https://api.runwayml.com/v1/generate"

    headers = {
        "Authorization": f"Bearer {RUNWAY_API_KEY}",
        "Content-Type": "application/json"
    }

    data = {
        "prompt": prompt,
        "duration": duration,
        "aspect_ratio": "16:9"
    }

    response = requests.post(url, json=data, headers=headers)
    return response.json()

# CNY-specific prompts
cny_broll_prompts = [

    "Dragon dance in celebration, bright colors, dynamic movement, festival crowd",
    "Chinese calligraphy brush writing blessing characters, rice paper, artistic"
]

for prompt in cny_broll_prompts:
    result = generate_cny_broll(prompt)
