## 5. Clipchamp Step-by-Step

### Step 1: Create New Project
1. Open Clipchamp
2. Create new project (9:16 aspect ratio)
3. Import your CNY screen recording

### Step 2: Add Music
1. Click "Audio" in left panel
2. Upload your CNY music file
3. Drag to timeline
4. Adjust volume (recommend 60-70% if no voiceover)

### Step 3: Add Text Overlays
1. Click "Text" in left panel
2. Choose "Plain text" or "Title"
3. Type text (refer to timing table above)
4. Adjust:
   - Font: Montserrat Bold (or similar)
   - Size: Large for headings, medium for subtitles
   - Color: White or Gold
   - Position: Top or center
5. Drag to correct position on timeline
6. Trim duration to match timing

### Step 4: Add Chinese Text
1. Add new text box
2. Copy/paste Chinese characters from this guide
3. Position below English text
4. Style with gold color

### Step 5: Add Transitions (Optional)
1. Between major sections, add:
   - Cross dissolve (subtle)
   - Or fade to black (dramatic)
2. Keep transitions short (0.3-0.5s)

### Step 6: Export
1. Click "Export"
2. Select 1080p
3. Export and save as "Forava_CNY_Introduction.mp4"
