# Forava App - Functional Objective

## 🎯 Core Mission
**Forava** is an AI-powered Rakhi creation and sharing platform that enables sisters to create personalized digital Rakhis and send them to their brothers, who can then receive them as functional Apple Watch faces and send gifts in return.

---

## 👥 Primary User Workflow

### **Sister/Female Friend (Sender)**
1. **Create AI Rakhi** → Design personalized Rakhi using AI-powered studio
2. **Choose Recipient** → Select brother or male friend from contacts
3. **Send Rakhi** → Choose delivery method (Apple Watch, Messages, WhatsApp, Email, Photos)
4. **Receive Gift** → Get payment notification when brother sends gift in return

### **Brother/Male Friend (Receiver)** 
1. **Receive Notification** → Get beautiful Rakhi notification on Apple Watch/iPhone
2. **View Rakhi** → Tap to see the personalized Rakhi in full detail
3. **Gift Popup** → After 3 seconds, AI suggests culturally appropriate gift amounts
4. **Accept & Send Gift** → Tap "Accept Rakhi & Send Gift" to pay via Apple Pay
5. **Watch Face Active** → Rakhi becomes functional clock face on Apple Watch

---

## 🔄 Complete Experience Flow

```
Sister Creates → AI Generates → Send to Brother → Brother Views → 
Gift Popup (3s) → Accept & Pay → Sister Receives Gift → Watch Face Active
```
